# Giaconi-Capra® PAS — Landing Page & Cotizador Web

Sitio web corporativo y cotizador de seguros para **Giaconi-Capra® Productores Asesores de Seguros**. Diseñado para ofrecer una experiencia moderna, accesible y optimizada en la conversión de clientes para coberturas individuales y corporativas.

---

## 🚀 Características Principales

* **Diseño Responsive & UI Moderna:** Interfaz pulida construida con Tailwind CSS, adaptada a dispositivos móviles, tablets y escritorio.
* **Catálogo Interactivo de Coberturas:** Navegación por pestañas (Personas / Empresas) y modales informativos con descarga simulada de documentación y manuales en PDF.
* **Formulario de Contacto Validado:** Validaciones en tiempo real (formato de email, sanitización de teléfono, límite de caracteres, captcha interactivo y aceptación de la Ley 25.326).
* **Carrusel de Testimonios:** Slider dinámico con temporizador automático, pausa al interactuar (`mouseenter`) y modal para la recepción de nuevas opiniones.
* **Integración con WhatsApp:** Botón flotante omnipresente con animación de atención y acceso directo a chat.
* **Normativa SSN & Legal:** Estructura preparada para el cumplimiento de la Superintendencia de Seguros de la Nación Argentina.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semantic Structure**
* **Tailwind CSS v3** (vía CDN / Configuración personalizada de marcas y colores)
* **Alpine.js v3** + `@alpinejs/collapse` (Gestión de estado reactivo y animaciones)
* **Lucide Icons** (Iconografía vectorial)
* **Google Fonts** (Tipografía *Plus Jakarta Sans*)
